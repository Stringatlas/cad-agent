## Design
Dimensions are local width/depth/height; local front is +Y. Yaw is counterclockwise around +Z from local axes. Access extends from front face, full box width, base-aligned, with separately specified height. Pole separation is inclusive minimum distance to original observed pole points, from box center or closed box volume (XY projection for horizontal metric); not cylinder/physical-pole clearance. Ground measurement explicitly uses sampled ground heights: least-squares plane slope and max-minus-min elevation over footprint samples; no continuous-support claim. AOI containment is inclusive XY footprint or footprint-and-access, independent of reference elevation. All listed thresholds are hard; ranking is lexicographic, separate from constraints. No automatic choice of ranking, orientations, thresholds or distance semantics. A semantically resolved request is not evidence of feasibility or an implemented search executor; search sampling/quality/budgets belong to later tasks.

Optional input parameter keys become explicit nulls; undefined values/unknown fields are rejected. Resolver rejects any null field. Assumptions name resolved fields and carry reasons. Outputs detach nested input values.
- No runtime consumer/tool is wired. Existing task044 code, presets, queries and approval paths are untouched. Missing `level` thresholds and distance/ranking choices remain clarification needs, not defaults. Resolved fixtures' numerical values are test inputs, not recommended standards.
- Yaws normalize one-turn [-360,360] input to sorted unique [0,360) values; positive decimals are preserved. Dimensions/positions are bounded at 1e7 per coordinate as a contract admission limit, not equipment recommendations. Rankings are ordered unique metrics with explicit minimize/maximize direction. Empty ranking explicitly requests no preference; missing ranking stays unresolved.
- Body/access conflict limits mean observed conflicts, not physical clearance. `box-center` is geometric volume center; `box-boundary` denotes nearest distance to the closed box (zero for interior points), not distance to its shell. Horizontal metrics project to XY. Terrain algorithm identity belongs in the explicit terrain revision; future search must bind its sampling/evidence policy separately and cannot claim continuous support from these thresholds.
