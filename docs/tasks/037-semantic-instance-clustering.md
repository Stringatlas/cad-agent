# Task037 — bounded offline semantic instance clustering

## Scope and acceptance
Implement now, no HTTP/UI or authoritative mutation. Consume the complete read-only semantic disk index for Pole/Car/Fence (optional Building), not a viewer LOD. Use class-specific occupied-voxel 26-neighbor connected components; no ground surface or fitting. Preserve every selected original `(sourceFileId, sourceRow)` membership and physical record ordinal. Deterministic instance IDs bind source artifact/content, frame, units and algorithm/settings. Explicit occupied-cell, output, manifest and time budgets fail without publishing partial results. Never allocate per whole-cloud point. Tests must cover class separation, voxel boundaries/negative coordinates, deterministic membership/IDs, exact coverage, budgets, cancellation and stale/corrupt input. Validate actual full-resolution data if available. Fresh-session review pending.

## Design
Two sequential checksummed page passes: collect occupied cells and union adjacent cells; then stream exact point memberships. Memory is O(occupied selected-class cells + existing disk-index metadata), not O(78M records). Voxel graph, not Euclidean DBSCAN: touching diagonal voxels connect, isolated cells survive, no min-size/noise rejection. Connected instances are geometric hypotheses, not verified individual physical objects. Defaults are initial class-dependent heuristics, not calibrated segmentation quality.

- `apps/server/src/semantic-instances.ts`: independent offline two-pass voxel components; 26 probes/cell; exact binary membership stream, stable IDs, revision/content/frame/settings binding and atomic all-or-nothing directory publication.

- `scripts/check-semantic-instances.ts`: independent complete original-payload membership/count/checksum audit, not a second connectivity oracle.
