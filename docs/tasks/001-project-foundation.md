### Resolved setup/check failures

- Initial pnpm shim selected unavailable pnpm 12.11.2. Root `packageManager` pin fixed selection; no global tool installed.
- Installed browser daemon could not resolve peer `typebox`. A temporary daemon process used existing Pi dependency resolution through `NODE_PATH`, with no package/config changes. Startup logs: `/tmp/pi-browser-daemon-repair.log`.
- Chrome initially lacked reachable remote debugging; it subsequently became available and both harness and CDP smoke connected. The smoke script itself is independent of Pi.
- First browser smoke detected a favicon 404; added an inline empty favicon. Rerun passed without filtering console errors.
